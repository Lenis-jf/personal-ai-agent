# Personal AI Agent

A small personal AI agent designed to experiment with **AI agents, LLMs, tool use, and automation** while exploring practical ways to integrate AI into everyday computer workflows.

The project is intentionally built from scratch to understand how the different components of an AI agent work together and to experiment with emerging technologies in a practical way.

## Goals

* Build a modular AI agent that can interact with the local computer.
* Experiment with **LLMs, Skills, tools, memory, and RAG**.
* Automate repetitive tasks and simplify everyday workflows.
* Explore both local and cloud-based AI models.
* Learn how agentic systems can safely interact with external tools and data.
* Build something useful while experimenting with new technologies.
